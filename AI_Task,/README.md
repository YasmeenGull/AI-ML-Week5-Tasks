# 📌 Project Objective

This project demonstrates the implementation of an AI-based intelligent prediction system using Machine Learning.

The system performs:

- 📂 Data Loading
- 🧹 Data Preprocessing
- 🤖 AI Model Training
- 🎯 Prediction System
- 📈 Accuracy Evaluation
- 📊 Result Visualization
- 👨‍💻 User Input Handling
